## 用户已确认

- 采用 B：首条内容由输入区连续交接到消息气泡，键盘与输入栏同步退场。
- 点击立即进入待发送画面，不等待服务端回执；待发送不等于成功。
- 机器／项目按钮原位淡出，所选目标由页头信息承接。
- 纯文字、图片／视频、文件、多附件、仅附件都保留完整内容；多附件整组移动，内部横排到纵排短淡变。
- 真正受理后原位确认；失败保留输入及真实错误，结果不明显示待确认并防止重复发送。
- 仅在首次新会话发送触发，保留历史会话正文无叠化、阅读和回底行为。

## 实现与验证

1. 原生会话层增加独立首条发送呈现状态，通过同一命令 ID 和业务快照确认，原始草稿继续由共享 runtime 管理。
2. 稳定输入栏宿主；动效只作用于首条内容和目标按钮，不给整个正文添加隐式动画。
3. 在发送前截取输入内容区域到内存，源内容与最终消息交接；支持减少动态效果，不记录用户内容到磁盘。
4. 执行状态层回归、原生构建和 iPhone 17 Pro 正常字号竖屏 UI 验证，检查慢 ACK、失败、待确认、附件及切换上下文。
5. 录制独立离线界面夹具的视频，明确是动效演示；不创建远端测试会话，不代替真实发送协议验证。
6. 同步现行交互约定；在共享 main 写入互斥下整合并推送，通过后交付视频与源码状态。
