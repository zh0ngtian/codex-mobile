# 侧栏控件截图对齐

范围：搜索、Chat、设置三个入口；沿用当前业务动作、侧栏数据与指定集成分支，更新 iPhone 17 Pro 模拟器，不发布渠道。

## 参考归一化与测量

参考图为 728×1988 像素的侧栏裁剪图，无可用状态栏或设备倍率元数据；不把图像像素直接当作 SwiftUI 点。以目标侧栏宽度 402×0.8＝321.6pt 归一化，比例约 0.442pt/参考像素（推断）。

| 项目 | 参考测量/推断 | 第一轮目标 |
| --- | --- | --- |
| Chat 粉色区域 | x78…320、y1810…1911，243×102px（实测） | 约107×45pt（归一化推断） |
| Chat 填色 | 中位 RGB(254,70,169)，约 #FE46A9（实测） | 粉色主题局部调节玻璃 tint，截图复核合成色 |
| Chat 图文 | 白色、文字较突出；图标在左（观察） | 以正文 ScaledMetric 缩放的 semibold，主题对比前景色；保留 Chat 文案与现有 SF 图标 |
| 设置 | 约104px直径的浅色圆形，深色齿轮（推断） | 约46pt 圆形系统玻璃按钮 |
| 搜索 | 无底色的深色放大镜（观察） | plain 图标按钮，44pt 点击区域 |
| 页脚水平位置 | Chat 左边距78px、设置右边距约45px（实测/推断） | leading34pt、trailing20pt |

参考列表中的模糊内容视为隐去的业务资料，不重建模糊图像或改变当前会话。只实现原生控件，不使用截图作为界面资产。当前主要差异是按钮过小、Chat 黑色图文、搜索多余的玻璃底及设置的椭圆形状。

## 验证

1. 按上述尺寸、颜色和形状做第一轮调整；复用现有玻璃按钮封装，不改公共按钮样式。
2. 构建后导出侧栏截图，以侧栏等宽归一化对照参考，按最大的视觉偏差修正。
3. 运行侧栏布局与真实网关搜索/设置现有用例，核对动作可用，提交推送并停留模拟器供用户验收。

## 最终校对与验证

- 已实现并在 iPhone 17 Pro 竖屏下完成四轮截图校对，使用侧栏等宽的728×1988归一化图比较清晰可见的控件；参考顶部裁剪元数据未知，保留目标设备系统顶部安全区，不按图片绝对 y 值移动标题。
- 最终 Chat 填色区域241×101px、文字81×26px、图标39×40px，对应参考243×102px、81×26px、39×39px。填色中位RGB(255,68,167)，参考(254,70,169)。
- 设置圆形修正了普通玻璃按钮不对称内边距造成的视觉偏移；底部去掉额外12pt留白，边距按可见轮廓核对。图文基准字号18.25/21pt通过 ScaledMetric 随系统正文设置缩放。
- 复用原生玻璃按钮材料，仅在这两个页脚控件裁切过强的外部光晕并加细描边与浅阴影；不修改全局材料。
- 最终布局/设置入口及真实网关搜索/设置两个用例通过，无新建业务测试会话。当前状态：模拟器已验证，待用户视觉验收。
