# 对话参考样式与模型能力修正

本次范围：用户列出的九项修正；仅在 iPhone 17 Pro 模拟器验收，不发布渠道或安装真机。

1. 先补紧凑用时、模型独立强度目录、隐藏工具活动的回归用例。
2. 普通正文保留系统 Dynamic Type 与粗体环境，Markdown strong/标题另加粗；对照参考截图复核字形与字号。
3. 补齐全部 commentary 灰线；运行转圈中性灰；缩小发送按钮；顶部符号 light；项目仅显示名称。
4. 将各模型支持的强度由现有业务能力目录送到原生层，模型切换后等待业务归一化快照，不发送旧模型强度。
5. 执行相关源码回归、构建与模拟器交互测试；正常模式留在指定网关供用户验收，提交并推送分支。
