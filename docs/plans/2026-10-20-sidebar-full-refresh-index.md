# 整轮刷新摘要索引与无项目分页

状态：代码实现与1735项回归、类型检查、前后端构建已通过，模拟器性能对照进行中；不发布客户端、不部署生产网关。

## 目标与顺序

1. 网关集中核对运行、关注与未读摘要，复用同一上游连接内的元数据索引与在途读取；上游断线后失效，状态变化事件使相关摘要重新核对。
2. 无项目仅在客户端提供的候选 ID 内排序与过滤，由网关返回五条和游标；更多再取五条，不扫描全局历史、不读取正文。
3. 在独立 iPhone 17 Pro 模拟器正常字号竖屏复测。整轮从启动命令计时，另列 Web 文档之后耗时；前者含既有约 2.4 秒容器启动，不能用后者冒充整机冷启动。
4. 前两项完成后仍超过 1 秒，再比较后台并发 2、4、6，并检查刷新期间打开会话延迟。按实测选择，不预先修改默认值。

## 实施与验收

- 新的只读 mobile/sidebar RPC 同时支持 HTTP 与 WebSocket；不修改写请求去重和未知结果恢复。
- 索引只保存摘要；冷索引初始化与热索引下的 App 冷启动分别记录，不能隐藏首次补查成本。
- 覆盖运行结束、事件与读取竞争、断线重连、相同 ID 在途去重、子会话与归档过滤、无项目最近五条与游标范围校验。
- 前台操作继续立即派发，后台队列仍让出前台；完整运行汇总与五条展示规则保持。
- 模拟器使用独立本机测试网关连接同一真实上游；生产网关与固定渠道不改动。测试配置与原始记录留在仓库外，报告仅提交脱敏计数与耗时。
- 通过相关回归、类型检查和必要构建，更新交互约定与测量报告，提交并推送分支。
