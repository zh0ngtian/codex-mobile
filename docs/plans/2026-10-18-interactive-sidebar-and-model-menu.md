# 交互式侧栏与模型菜单实施计划

**Goal:** 完成本轮五项界面要求，用户已确认思考强度也按当前模型的真实档位改为菜单选项。

**Architecture:** 侧栏保留4/5宽度，以单一手势位移驱动主界面的位移、圆角和阴影；结束时才同步现有侧栏业务状态。模型/强度采用原生菜单普通按钮，Fast独立切换；沿用现有业务命令和权威快照。

**Tech Stack:** SwiftUI NavigationStack、Menu、方向受控的UIKit Pan、UIKit图片预览及现有业务桥。独立worktree内顺序实施，不发布渠道。
