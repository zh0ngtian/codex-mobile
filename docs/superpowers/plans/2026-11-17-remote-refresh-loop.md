## 原因与修复范围

真实网页中 Remote 的后台快照更新仅需约 1.4–3 秒，但运行会话的 updatedAt 持续变化；`mobile/readSnapshot/updated` 每次触发整轮 loadThreads，重新发起其他过期快照的上游更新，产生反馈循环。刷新按钮结束只代表缓存交付完成，不能据此报告上游同步完成。

保留共享快照、原身份/目标隔离及手动刷新。后台通知重新投影列表时，只读取已授权网关快照，不再次启动上游更新；正常首次加载、手动刷新及定时置顶同步保持既有更新能力。该选项仅为前端传输内部参数，不修改公开 URL 或 RPC 参数。缓存未命中和旧网关继续沿原有 RPC 规则。状态必须反映实际后台任务，不可因缓存仍过期而虚报正在刷新。
