# Sidechat 实施计划

> 使用 superpowers:executing-plans 在当前会话逐项执行；不派生子代理。

**目标：** 从主聊天最近结束回合创建临时独立 Sidechat，完成三端接线，并停在模拟器供用户验收。

**架构：** 专用管理器拥有分支关联和内存消息投影，复用现有 AppServerClient、会话页面、输入和 NativeSnapshot。普通聊天流程与分支事件分流，Codex 维护真实聊天内容。

**技术栈：** TypeScript、React、Vitest、SwiftUI、XCTest、Codex App Server V2。
