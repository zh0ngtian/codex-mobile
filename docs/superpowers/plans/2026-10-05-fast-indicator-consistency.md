# Fast 图标与速度设置一致性修复

## 现象与原因

服务端设置通知可能携带 `normal` 等非空但不属于当前模型 `serviceTiers` 的值。原实现以“值是否非空”决定是否显示闪电，同时菜单以“能否匹配当前模型档位”决定标签，因此会出现顶部有闪电、菜单却显示正常的矛盾状态。

## 目标行为

- 服务端模型设置通知进入客户端后，按当前模型目录归一化模型、智能和速度。
- 只有当前模型实际支持且已选中的非默认速度档位才显示闪电。
- `thread/start`、`turn/start` 和历史消息重发只发送归一化后的速度值；普通速度始终发送 `null`。

## 验证与交付

1. 先在端到端测试中注入 `serviceTier: "normal"`，确认旧实现错误显示闪电。
2. 归一化实时设置通知，并让界面和请求统一使用有效速度值。
3. 运行专项端到端测试、全量单测、类型检查和生产构建。
4. 提交并推送，构建 0.2.66 APK，发布固定局域网渠道并在真机验证。
