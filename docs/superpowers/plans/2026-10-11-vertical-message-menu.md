# 原生菜单直接纵向展开

目标：仅调整长按菜单，所有操作直接纵向显示，不分页、不增加子菜单；保留现有消息布局和编辑流程。

实现：iOS 17.4+ 使用 UIButton 的原生 UIMenu 与 performPrimaryAction，根菜单只包含 UIAction；iOS 16–17.3 使用系统纵向 action sheet。Android 与网页现有纵向平级菜单保持原样。
