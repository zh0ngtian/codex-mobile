# 字体大小调整实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Web、Android 和 iOS 支持立即生效、重启保留的四档字体大小。

**Architecture:** 使用独立字号偏好模块校验本地存储值，启动时设置根字号缩放变量。将 CSS 中固定字体大小换算为 rem，保持默认视觉尺寸及布局尺寸；管理设备中加入四档选择。

**Tech Stack:** React、TypeScript、CSS、Vitest、Playwright、PakePlus。
