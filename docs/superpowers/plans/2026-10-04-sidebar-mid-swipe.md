# 会话中部右滑呼出侧栏实施与交付计划

> **执行要求：** 当前环境未暴露 superpowers Skill；用户已确认按仓库现有 superpowers 计划格式和 TDD 流程执行。

**目标：** 在会话页面中部向右滑动时打开侧栏，同时保留左边缘入口，并避免与输入、弹层、纵向滚动和横向滚动内容冲突。

**现状证据：** 原有 `ConfiguredApp` 的全局触摸监听只记录 `clientX <= 24` 的起点，因此从屏幕中部开始的右滑不会打开侧栏。

## 任务 1：先写失败的手势测试

1. 增加会话中部右滑测试，断言超过位移阈值时只打开一次。
2. 覆盖左边缘、纵向滚动、多指触控、输入区、弹层和横向滚动区域。
3. 先运行聚焦测试确认失败，再实现手势逻辑；随后运行聚焦测试、完整测试和构建。

## 任务 2：实现并集成手势

1. 将侧栏手势识别抽成独立 Hook，限定在可见会话工作区。
2. 保留现有水平位移阈值，增加纵向偏移、多指和反向移动取消条件。
3. 在顶层应用调用 Hook，保留原有侧栏历史记录及返回键处理。

## 任务 3：提交与固定渠道交付

1. 检查暂存内容和提交规范，提交并推送本次改动。
2. 读取固定渠道当前版本；将移动端版本基线调整到至少该版本，使自动构建版本更高。
3. 推送主分支后下载该提交对应工作流构建的 APK；核对构建版本、嵌入资源和摘要。
4. 使用 `apk-server.py publish-channel codex-mobile` 发布，通过固定 JSON、HEAD、GET 核对版本、文件大小和 SHA-256。
5. 清理本次不再需要的临时文件。
