# 弱网图片文件预览修复计划

## 目标与现象

用户点击中文电脑图片链接后停留在“正在读取文件”。之前只验证了首次会话响应的限速耗时；本次验证必须覆盖图片文件链接、原图读取和下载。

## 修复路径

- 先在手机限速、高延迟条件下复现大图片 `fs/readFile` 的问题，记录请求和 UI 状态。
- 为图片文件链接增加先显示缩略图、再读取原图的回归测试，检查轮询重绘不重复读取。
- 图片文件预览复用带认证的 HTTP 图片接口，避免将大图塞入短超时 RPC；保留旧网关和无网关回退。
- 原图慢或失败时保留缩略图和原文件下载入口，提供明确失败状态及重试。
- 在实际手机完成弱网预览、原图完成和文件下载校验；恢复网络设置并清理临时测试进程。
- 运行相称测试和打包检查，提交推送，发布高于固定渠道的 APK，通过 JSON、HEAD、GET 验证版本、大小与 SHA-256。
