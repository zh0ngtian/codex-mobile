# 历史回合代码改动计数修复

## 现象与原因

真机 v0.2.63 打开已完成回合时，界面显示“本次代码改动 0 行”；同一回合的 app-server `itemsView: full` 包含文件改动，而 `itemsView: summary` 只包含用户和助手消息。当前客户端只读取 summary，因此把缺失数据误当作零改动。

## 计划

1. 先写失败测试：精简回合未取得改动统计时不能显示 0；完整历史页的文件改动可回填到精简回合。
2. 保留现有精简记录加载，异步读取对应完整页，只提取新增和删除行数，丢弃大型工具输出。
3. 为首屏、历史分页和合并回合回填统计；防止旧会话的异步结果覆盖新会话。
4. 跑针对性测试、类型检查和构建；提交推送，构建并发布更高版本 APK，在真机复测并截图。
