# 常驻 Remote 网关：已确认设计

日期：2026-11-13。源码基线：`7772b28f5e716d8e5e3759fb1e84a089158502ec`。本设计及[Mac管理与身份恢复补充方案](2026-11-13-remote-gateway-cli-proposal.md)记录 Q1–Q45 的最终决定，后续修改不得恢复已被覆盖的单网关方案。

## 配置和交互

保留多个网关，每个网关只填一条现有格式的 URL，token 继续通用。网关各自保存本地/远程模式，旧配置默认为本地。模式选择放在 URL 表单旁；切换选项本身不检查、不生效，点击“测试并保存”才验证并原子保存。失败保留原连接、模式、输入和错误信息。

旧网关不支持 Remote、令牌错误、网关不可达、Mac 授权不完整、尚未与网关所在 Mac 配对分别提示。缺授权或配对时阻止保存 Remote；已配置的 Remote 临时上游离线仍允许保存并排队。进入 Remote 后认证撤销或离线都不自动降级为本地。

保存成功后进入对应模式的会话列表，保留草稿和阅读位置。Remote 首次选择网关 Mac，随后恢复上次机器；机器不再可用时要求明确选择，不按名称/IP 替换。机器菜单按网关分组，同一物理机器从不同网关进入时保留不同来源。

跨网关的队列、草稿、关注、缓存相互独立，不合并重复机器。共享排序只保证“同一网关、同一真实目标、同一会话”。同一网关本地和 Remote 访问网关 Mac 时共享会话身份、草稿、关注和队列，但传输/会话上下文隔离。某网关失联不由另一个接管；人工切换只影响视图和新操作，不搬迁旧操作。

## Remote 身份和边界

本地模式维持现有 canonical bridge，只控制网关本机。Remote 模式只通过官方 Remote，包括访问网关本机；可见目标仅限启用 Remote Control 且与网关自身 controller 配对的主机。SSH/WSL 独立转发不属于本期范围。

网关有自己的设备密钥、controller enrollment 和逐台配对，不继承或冒用官方 App 的 controller。一个网关绑定一个 OpenAI 账号/工作区，所有手机共用。Mac 端负责登录、注册、配对、目标管理和导出 URL。账号/工作区变化或授权撤销暂停原队列，Mac 显式恢复授权后再核验；普通网络故障自动重连。重装导致目标身份无法证明时暂停并重新关联，不按名称/IP 猜测。

Mac CLI仅通过当前用户专用的本机私有控制通道管理已运行网关，不使用手机token开放管理、不独立创建Remote主连接、不离线写入或自动启动网关。撤销后的新授权在独立私有记录中完成登记、本机配对和双ID证明，原完整受管身份不变后才原子切换，旧记录保留；准备期间停止旧主连接，不并行启动新主连接。原队列保持暂停，逐目标重新核验配对和完整身份后才允许Mac显式恢复；目标重装重新关联只影响后续访问，不改写旧操作。崩溃后只采用已提交活动指针。两项于2026-11-13确认，具体边界见补充方案。

## 持续连接和观察

每个网关账号/工作区一条常驻官方物理 WebSocket，多机器、多手机的逻辑 RPC stream 在其上复用。请求、通知和审批归属隔离；没有独占手机，一次审批完成后其他手机同步或收到过期错误。会话不各建物理连接。

手机打开过的会话由网关继续观察。事件立即更新；空闲每 60 秒检查，运行中、待审批或已关注每 3 秒检查。每个网关来源最多 4 个后台操作，前台优先，积压可见且不丢会话。心跳与会话检查分开，网络活动、重复读取不能延长业务更新时钟。

首次观察建立基线并持久化真实业务变化时钟。24 小时无实际更新时仅释放会话观察/逻辑资源，主连接与用户数据保留；活跃手机、运行任务、待发队列、审批、通知/关注责任存在时不清理。离线或读取失败先对账，不能当作会话无更新。网关重启保留该时钟。

## 队列和不确定结果

所有需要上游的操作先持久化到网关再确认，展示等待、发送中、待确认、完成、失败。手机到网关也断开时保存本地 outbox，显示“待提交”，交给网关后其他手机才能看到。固定操作 UUID 支持丢 ACK 后查询收据，重复提交不重复执行。

同一网关/目标/会话的手机共享内容和状态；所有手机可编辑、取消未发送项，用 revision CAS 拒绝冲突，不静默覆盖。按网关收到的次序串行；停止和审批优先于下一轮消息，分别绑定原 turn 和原待处理请求。过期控制明确失败。

已经发送而丢失响应的写入进入“待确认”，只能对账，不自动重发；待确认/失败的队首阻止同一会话后续写入，其他会话继续。入队冻结目标、账号、模式、设置与附件；切换模式不移动旧操作。读取允许合并，过时导航读取可以取消，写入逐条保留。

保持 128 条可见队列/64MiB 元数据上限，显式拒绝超额并保留输入，不淘汰旧项；控制操作有独立有界预留。附件单独持久化，不能清理仍被队列引用的文件。离线上游创建会话先显示共享“待创建”占位；确认后绑定真实 threadId，不确定的创建不重试。删除手机上的网关配置不取消共享队列；手机 outbox 暂停保留，草稿保留。

## 功能和验收

现有项目、会话历史、附件、原图、生成图片、Git/改动统计、关注、后续消息与 Bark 全量覆盖。附件保持单文件 100MiB/4 个文件；图片保持每张 10MiB、总计 20MiB/4 张；视频支持 Range。已移除的语音 UI 不恢复。

远程文件和 Git 只能通过目标的官方 fs/command 接口及其权限实现，不新增远端常驻 agent，不引入 SSH 或网关本地数据替代。必需能力不支持就是验收阻塞。

2026-11-13补充确认：仅固定的模型上传统计读取命令使用 `sandboxPolicy: { type: "readOnly", networkAccess: true }`，其他操作保持默认权限。该例外不能由客户端用于任意命令或通用文件/Git操作。隔离验证已通过当前Mac的socket连接、目标路径及来源校验，统计快照、持续更新和产品接入仍待验收。

验收目标：连续 8 小时并跨凭据过期，多次手机离开/重进，Mac 睡眠/唤醒，网关进程重启；健康网关重入 P95 ≤2 秒，有效认证、网络和清醒目标下上游恢复至首次轻量 RPC P95 ≤10 秒。此前五分钟成功只证明初步连通，不等于这些目标已验收。本次仅源码交付，不发布客户端、不部署现役网关。
