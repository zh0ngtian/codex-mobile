# ChatGPT 手机图标替换设计

用户要求将 App 图标换成 ChatGPT 最新图标，并提供手机桌面截图作为外观依据：Dock 内是白底、扁平黑色结形标志。采用与该截图一致的 OpenAI 帮助中心官方 1024×1024 素材，避免将 App Store 带立体高光、边框和灰色渐变的展示图当成桌面资源。

Android、iOS 和本机 iOS 准备流程继续读取现有 `docs/assets/app-icon/codex-mobile-app-icon-1024.png`。保留官方素材原件，离线生成不透明 RGB PNG，不缩放、不重画标志、不叠加手机图案，也不添加渐变、圆角和阴影。系统负责桌面圆角显示。

原 `scripts/compose-mobile-app-icon.sh` 改为从仓库内官方原件生成图标，保留默认输出与 `--output` 用法，移除旧叠层参数，防止后续再生成旧图。记录素材出处和原件 SHA-256。

先增加真实像素和生成结果回归，验证旧图不满足纯白边缘和扁平黑色要求；替换后要求尺寸 1024×1024、无 Alpha、外围纯白、与官方原件铺白后的像素完全一致。运行发布协调器必需的本地验证，提交推送固定 SHA，经 `codex-mobile-lan-production` 完成双端批次发布和渠道回验。不改网关运行逻辑。

本次不创建测试会话，不占用共享模拟器；这是资源替换，不能据此声称真机覆盖安装和数据保留已验证。
