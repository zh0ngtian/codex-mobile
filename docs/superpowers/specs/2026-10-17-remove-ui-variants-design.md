# 界面实现收敛设计

## 已确认的范围

用户要求移除新版 Web 界面和独立原生输入框模式，仅保留当前非原生界面和完整原生界面；用户已确认以下升级规则：保留“使用原生界面”的现有选择，未开启者使用当前非原生界面及网页输入框，首次安装也默认非原生界面。

## 实现边界

- 删除新版 Web 的专用组件、样式、偏好 Provider、开关和条件分支，保留原有非原生交互与业务状态。已保存的新版偏好不再参与界面选择。
- 删除网页原生文字编辑器、布局代理、几何/焦点/选区桥、独立 composer 偏好及命令、快照字段和相关混合呈现分支。旧 composer 偏好不再读取或生效。
- 保留完整原生界面的 NativeComposerView 及其附件、模型、审批、草稿、队列、正文编辑和选区处理；只删除混合模式专用依赖。
- 保留单一业务 WebView、可信主文档校验、原生界面切换前的数据检查点、切换失败回滚以及人工恢复当前非原生界面的能力。
- 删除专用测试与离线 fixture，迁移其中仍适用的业务回归；新增升级旧偏好仍使用正确界面的行为验证。历史设计和验收记录保留，现役 README/桥接文档与发布日志同步。
