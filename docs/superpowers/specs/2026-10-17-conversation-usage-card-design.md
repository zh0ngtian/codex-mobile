# 对话用量与额度卡片

用户已于 2026-10-17 确认本方案，并要求 token 使用 K、M 缩写。

## 展示与交互

对话页顶部圆圈按钮打开图标下方的白色圆角卡片，标题为「用量与额度」。沿用参考图片的左侧灰色标签、右侧深色加粗数值、宽松行距和浅色边框。卡片包含「上下文余量」「周期剩余」「时间剩余」「对话 Token」四行，不再在这个入口展示线程 ID、目录或重置日期。

「上下文余量」沿用最近模型请求 token 与上下文窗口的计算；「周期剩余」展示 7 天额度剩余；「时间剩余」展示 5 小时额度剩余。百分比四舍五入为整数。账户额度不是单会话额度。

「对话 Token」读取当前会话 `tokenUsage.total.totalTokens`，不使用 `last` 代替累计消耗。小于 1000 显示整数；1000 及以上使用 K，1000000 及以上使用 M，保留最多一位小数，去掉无意义的 .0，避免边界值出现 1000K。示例：950、1K、128.5K、3.1M。

无效、缺失数据展示「暂无数据」，不虚构 0% 或 100%。数据变化时卡片实时更新，切换对话后不显示上一会话用量。点击外部、Escape 或再次点击圆圈可关闭；关闭后焦点回到触发按钮。卡片不能超出屏幕或遮挡后无法关闭。

## 实现范围

复用现有 `thread/tokenUsage/updated` 与账户 rate limits 状态，仅修改客户端展示。不会新增服务端存储或查询接口，也不为获取 token 而额外 resume 历史会话。新文案加入既有中英文映射。

## 验证与发布

先用 Vitest 验证四行口径、K/M 边界、缺失数据与关闭交互，再验证 iPhone 17 Pro 正常字号竖屏的卡片位置、截图与交互。发布任务 `conversation-usage-card-20261017` 已登记在 `codex-mobile-lan-production`，本地验证、推送和 ready 后由协调器完成统一版本 APK/IPA 发布和渠道验收。不涉及网关变更。
