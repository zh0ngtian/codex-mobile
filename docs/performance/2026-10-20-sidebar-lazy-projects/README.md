## 当前规则

- 已知折叠分组不预取首批。自动刷新只读取目录、全部关注/未读/运行摘要，以及当前展开的分组。
- 普通项目与无项目均在点击展开时读取本组五条；运行计入五条，更多按五条累计。再次收起重开重新读取首批。
- 新添加设备全部分组默认折叠，用户显式选择跨重启保存；既有设备的原折叠记忆保持。后续出现但未显式展开的项目也默认折叠。
- 未查询的折叠组不阻塞整轮结束，不把正常折叠目录显示成成功空会话；全局摘要继续给折叠标题提供运行和未读汇总。
