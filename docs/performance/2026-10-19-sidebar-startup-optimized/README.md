2026-10-19（Asia/Shanghai）。基线 14:01:13—14:07:11，优化版 14:08:14—14:13:20；末次时间为启动时刻。

## 范围与对照

- 用户确认：每个项目分组（含无项目）首批最近5条普通会话，点击加载更多再增加5条；关注、未读、运行摘要独立保留。只做模拟器验证，不发布。
- iPhone 17 Pro / iOS27.0 / 正常字号 / 竖屏 / 0.3.8（3008）Debug。两组各30次进程重启，每组另有2次校准已排除，保留设备配置、HTTP会话、App数据与服务端/磁盘缓存，使用同一真实网关。
- 两组原生可执行文件及debug dylib完全相同；Web业务分别基于`219fad454779f25a252d20c0eddb200696025441`与`87a13f67f619c5fa6bd94548d88f46d35c75c88b`。基线主JS散列与[此前30次基线](../2026-10-19-sidebar-cold-start/README.md)相同；本表重新采样，保证前后使用同一原生容器。
- 起点为调用simctl launch前，使用宿主机墙钟与performance.timeOrigin + performance.now()对齐；终点是JS将本轮新数据提交原生快照派发入口，包含启动调用开销，尚未包含Swift解码、原生布局及真实屏幕显示。
- 首批终点要求真实优先摘要返回后有包含会话行的快照；全部分组终点要求本轮onSettled及随后快照。全部分组指各组初始分页和必要补取，保留现有折叠状态；未额外点开历史分页。
- 采样顺序为基线后优化版，正式采样期间不运行测试、构建、UI树或截图轮询。时段负载及Debug/模拟器对绝对数值仍有影响，不据此声称真机Release的可见首帧。
