## 口径与限制

终点直接记录加载ProgressView的onDisappear，不使用整个页面稳定时间。WebKit请求前等待为PerformanceResourceTiming.requestStart-fetchStart，包含调度/跨域预检；DNS及连接阶段为0。临时网关副本增加Server-Timing，连接同一真实上游；生产网关及转发进程未修改/重启。正文、原始会话ID、网关口令和设备配置不进入本目录。

模拟器使用从当前配置只读复制的设备、偏好与关注记录；没有复制HTTP会话ID、未确认写入、草稿或通知订阅。两组保持同样的额外诊断代码与页面状态。后台负载会波动，样本量10及Debug/模拟器结果不作为真机或Release性能SLA；快照诊断本身也有少量开销。
