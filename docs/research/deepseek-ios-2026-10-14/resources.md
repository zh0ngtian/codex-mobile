## AX资源标识

完整去重表见[image-identifiers.json](image-identifiers.json)，共25个Image标识，每个附实际状态编号。标识的存在只证明AX报告了这个字符串，不证明文件格式、授权或API。

| 类别 | 实际观察标识示例 | 含义边界 |
| --- | --- | --- |
| 系统样式标识 | `chevron.forward`、`checkmark`、`magnifyingglass`、`clock.fill`、`person.2.fill`、`folder.fill`、`circle` | 部分来自系统文件选择器；不能据此假定全部使用SF Symbols |
| 字体尺寸 | `settings/fontSize/fontSizeSmaller`、`settings/fontSize/fontSizeLarger` | 字体设置页图片标识；非字体文件名 |
| 文件来源 | `chat/file_upload_menu/folder24`、`chat/file_upload_menu/wechatOutline24` | App菜单图标；没有获取原图 |
| 用户菜单 | `chat/message/editAction`、`copyAction`、`selectTextAction`、`shareAction`（同前缀） | 命名提示动作用途；源文件与渲染方式未知 |
| 助手菜单 | `chat/message/regenerateAction`、`likeAction`、`dislikeAction`、`tts_play`、`selectAllAction` | 长按/选区菜单中可见 |
| 会话菜单 | `chat/session/edit`、`pin`、`delete`（同前缀）、`sessionList/multiSelect` | 会话操作图标 |
| 分享选中 | `Message/shareEnable` | 分享选择页选中图标 |

多数顶部与输入图标没有Image id，而是Button标签：`open_sidebar`、`sessionTTSAutoPlayButton`、`sessionNewChatButton`、`voice`、`text`、`上传文件`、`发送`、`停止`。这些标签适合定位控件，不能当作图片文件路径。

## 视觉变量与缺失资源

| 资源 / 参数 | 现有依据 | 尚缺内容 |
| --- | --- | --- |
| 背景与文字 | 浅色白底黑字、深色深灰底白字；次级字灰色 | 源色值、动态语义颜色、对比度测量 |
| 强调色 | 模式、发送、选中圆点、品牌图形为蓝色 | 精确HEX、不同状态透明度与深色变体 |
| 气泡 / 代码块 | 用户淡蓝、代码块近白灰 | 精确色值、边框、连续消息圆角规则 |
| 圆角与投影 | 大圆角输入卡、设置组、浮层、圆形/胶囊导航 | 真实半径、连续圆角、阴影参数、材质配置 |
| 字体 | 中文无衬线、标题粗体、代码等宽 | 字体家族、字号/字重/基线/行高与Dynamic Type映射 |
| 图标 | 线性轮廓、约20–24pt菜单图标、21pt消息动作报告框 | 向量路径、光学尺寸、触控扩展、无障碍标签 |
| 空态图形 | DeepSeek蓝鲸标志 | Codex Mobile自己的品牌图形与空态文案需单独确认 |
| 音色动态图形 | 两张采集帧有不同形态 | 动画源、帧率、色阶、录音/播放同步行为 |
| 导航动画 | 抽屉展开后0.95左右缩放及右移 | 动画时长、弹簧参数、交互手势、减弱动态效果 |
| 键盘同步 | 本机输入卡随键盘和内容增高上移 | 系统键盘、第三方输入法、高度变化、交互式收起完整矩阵 |
| 文本渲染 | 标题/列表/Swift语法色、选区 | 表格、链接、LaTeX、长代码横滚、HTML及复杂Markdown边界 |

本次没有用估计数值填充缺失设计变量。后续如要求忠实复现，应补量上述参数，并先确认采用范围。
