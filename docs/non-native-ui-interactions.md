# 非原生界面交互说明

本文按“有哪些界面、界面上有哪些按钮、点击后发生什么”描述当前已经实现的交互，供产品梳理、界面改版和功能对照使用。

- 整理日期：2026-10-17。
- 代码基准：远端 `main` 的 `1153c9f`。这是代码行为说明，未进行本次真机逐屏验收，也不据此推断各下载渠道正在运行的版本。
- 范围：Web、Android 和 iOS 中由网页实现的界面，包括旧版、新版及共用面板；不展开完整 iOS 原生界面和系统选择器自身的按钮。
- 按钮名称使用中文界面的文字；只有图标的按钮用其功能名称标识。设备、模型、项目及审批选项取决于实际连接的数据。

## 1. 界面模式与整体导航

### 1.1 两套非原生界面

| 模式 | 入口与特征 | 切换方式 |
| --- | --- | --- |
| 旧版网页界面 | 首次使用的默认网页模式；侧栏顶部直接展示草稿、刷新、管理设备，底部为搜索框和“聊天”按钮 | 侧栏右上角“管理设备” → 开启“使用新版界面” |
| 新版网页界面 | 全宽侧栏、粉色用户气泡、浮动输入框；侧栏顶部使用“Codex”菜单，设置按类别分子页 | 侧栏“Codex” → “设置” → 关闭“使用新版界面”可回旧版 |

“使用新版界面”保存后立即切换，只影响当前客户端。两套界面共用设备、会话和未发送内容。

iOS 还存在两个独立开关：“使用原生界面”和“使用原生输入框”。当前 iOS 默认可以是“网页历史 + 原生输入框”的组合；此时本文中的网页输入区会被原生输入栏替代。需要对照完整网页输入区时，应关闭“使用原生输入框”并完整重启 App。整页原生开关与网页新版开关互不替代，整页原生模式开启时使用原生界面。两个 iOS 开关均在下次完整启动 App 时生效，普通前后台切换不生效。

### 1.2 界面清单

这里的“界面”包括主页面、侧栏、菜单和覆盖在当前页面上的底部面板，不一定对应独立网址。

| 界面 | 从哪里进入 | 用途与下一层 |
| --- | --- | --- |
| 无设备引导页 | 当前客户端没有设备配置 | 添加第一台设备 → 设备连接表单 |
| 会话列表侧栏 | 对话页左上角；支持向右滑开 | 选择设备、搜索、项目分组、打开会话、新建对话、进入草稿或设置 |
| 会话操作菜单 | 长按/右键会话行，或详情右上角“…” | 关注、刷新、复制会话、复制 ID、重命名、归档 |
| 新对话页 | 旧版“聊天”；新版“Ask Codex”或详情右上角新建图标 | 选择机器和项目、编辑内容、保存草稿；首条消息发送时才创建远程会话 |
| 对话详情页 | 点击会话；点击通知；发送新对话首条消息 | 查看历史、继续提问、停止、排队、编辑历史、打开文件与图片 |
| 输入设置面板 | 输入区的模型、权限、速度入口 | 选择模型、思考强度、速度、权限模式 |
| 上下文/额度面板 | 对话右上角圆环 | 旧版为“状态”底部面板；新版为“用量与额度”浮层 |
| 草稿箱 | 旧版侧栏“草稿”；新版“Codex → 草稿” | 恢复或删除本地新对话草稿 |
| 管理设备/设置 | 旧版侧栏“管理设备”；新版“Codex → 设置” | 设备、语言、字号、传输、通知和界面模式 |
| 设备连接表单、扫码界面 | 添加/编辑设备 → 扫码图标 | 填写连接地址、识别二维码、测试并保存 |
| 审批面板、问题表单 | 服务端请求审批或补充回答时自动出现 | 允许/拒绝操作；填写、暂存和提交回答 |
| 图片、视频、远程文件预览 | 点击消息中的媒体或文件引用 | 查看、缩放、播放、切换预览/源码、下载 |
| 应用更新面板 | Android 检测到更新时 | 查看更新说明、下载安装、失败重试 |

### 2.4 两套侧栏共用的列表交互

| 操作 | 点击或手势后的结果 |
| --- | --- |
| 点击会话行 | 切到该会话所属设备、关闭侧栏并打开详情；进入时清除该会话未读标记 |
| 长按会话行/鼠标右键 | 打开会话操作菜单，见第 3 节；iOS/Android 优先使用系统菜单，浏览器使用网页菜单 |
| 点击项目名称/文件夹图标 | 展开或收起该项目，不会打开文件浏览器，也不会新建对话 |
| 点击项目中的“更多” | 每次追加显示 5 条普通会话；需要时向服务端继续加载 |
| 收起项目后再次展开 | 恢复为前 5 条普通会话，再点“更多”继续查看 |
| 点击“加载失败，点击重试” | 只重试该项目的会话加载，不跳转页面 |
| 输入搜索关键词 | 展示匹配结果和可用的匹配片段；匹配项目临时展开，清空搜索后恢复原折叠状态 |
| 向右滑动对话区域 | 打开侧栏；向左滑侧栏可关闭。输入框、弹窗、可横向滚动内容及历史编辑状态会避让此手势 |
| 点击侧栏遮罩 | 关闭侧栏；新版侧栏占满屏幕时主要使用左上角按钮或滑动关闭 |

会话行的运行转圈、未读圆点、时间，以及设备连接点和待审批数字用于展示状态，不是独立按钮。项目收起时在项目名旁汇总运行/未读状态；展开后在具体会话行展示。新版视觉上隐藏了会话行的时间和来源副标题。

“关注”会话只出现在顶部关注区，不在原项目重复显示；运行中和未读会话不会自动升入关注区。内部辅助、子 Agent、记忆整理等会话被过滤，不占普通列表的分页名额。

## 3. 会话操作菜单

入口一是侧栏长按/右键某条会话，入口二是已有对话详情右上角“…”；两者操作相同，但刷新范围不同。

| 菜单按钮 | 功能与结果 | 页面变化 |
| --- | --- | --- |
| 关注/取消关注 | 切换当前客户端对该会话的关注状态；关注后移到顶部关注区，取消后回原项目。关注也影响完成通知的覆盖范围 | 留在原界面并更新列表 |
| 刷新会话 | 从侧栏操作时刷新该会话摘要；从详情操作时重新加载该会话详情 | 不创建新会话 |
| 复制会话 | 通过服务端复制已有会话历史，生成独立的新会话并加入列表 | 显示“已复制会话”，不会自动进入副本 |
| 复制会话 ID | 把该会话的标识复制到剪贴板 | 收起菜单，不复制正文或整个会话 |
| 重命名 | 弹出名称输入框，预填当前标题；输入非空且不同的新名称后保存 | 成功后同步更新列表和详情标题；取消或名称不变则不修改 |
| 归档 | 从普通列表移除会话，并移除本地关注状态 | 归档当前打开的会话时收起详情、打开侧栏；归档其他会话时留在当前界面 |

有排队消息时，归档先确认是否丢弃队列，确认后才执行。处于只读模式时，复制会话、重命名、归档不可用；关注、刷新、复制 ID 仍可操作。菜单操作提交中会暂时禁用其他动作。

## 4. 新对话页与对话详情页

### 4.1 顶栏与新对话目标

| 按钮/控件 | 显示位置或条件 | 点击结果 |
| --- | --- | --- |
| 左上角列表图标/返回箭头 | 两版都有，新版使用返回箭头外观 | 打开会话列表侧栏，不删除会话 |
| 上下文圆环 | 旧版已有会话显示；新版新对话和已有会话均可显示 | 打开状态或额度面板，见第 6 节 |
| 新建图标 | 新版详情右上角 | 打开新的空白对话编辑状态；不会仅因点击就创建远程会话 |
| “…” | 旧版已有会话、新版新对话和已有会话 | 已有会话打开会话操作菜单；新版新对话只显示“保存草稿” |
| “选择项目”下拉框 | 仅新对话页 | 选择远端项目目录或“无项目”，作为首条任务的工作目录；留在新对话页 |
| “选择机器”下拉框 | 仅新对话页 | 将新对话切换到另一台已启用设备，保留当前文字和附件，项目按目标设备重新确定 |

新建入口会使用所选设备范围；在“全部”列表中优先沿用上次新建所用设备。项目选择会按设备记住。已有会话的机器和工作目录显示为说明文字，不能通过这两个下拉框迁移已有会话。

### 4.2 历史加载与消息操作

| 按钮/操作 | 功能与结果 |
| --- | --- |
| 加载更早消息 | 向前加载 5 个旧回合并保持当前阅读位置；滚动到顶部也会自动触发 |
| 更早消息区域的“加载失败，点击重试” | 重新请求旧回合，保留已经展示的历史 |
| 详情加载失败时的“重试” | 重新加载当前会话详情 |
| 只读提示中的“重新连接” | 再次尝试恢复会话的交互能力；此前保留历史可读，发送及修改类操作不可用 |
| 用户长消息的“展开更多/收起” | 在原位置展开或折叠正文，不改变消息内容 |
| 用户消息旁的“编辑” | 在原消息位置打开历史编辑器；新版快捷按钮在悬停或键盘聚焦时显示，也可使用长按菜单 |
| 用户消息长按/右键 → 复制 | 复制完整用户正文，不受长消息折叠影响；执行中仍可复制 |
| 用户消息长按/右键 → 编辑 | 与“编辑”快捷按钮相同；仅在允许历史编辑时出现 |
| “之前的 N 条消息” | 展开/收起该回复段之前的过程说明及其关联图片，不打开新页面；N 只统计过程说明 |
| AI 最终回复下方的复制图标 | 复制本回合当前已呈现的 AI 文本；收起的过程说明不在复制范围内。显示“已复制”或“复制失败”反馈 |
| Markdown 代码块的复制图标 | 复制该代码块原始代码 |
| Mermaid 的“查看源码/预览” | 在图表和 Mermaid 源码之间切换；复制图标始终复制源码；渲染失败时显示源码 |
| 文件引用、消息图片 | 打开对应预览面板，见第 10 节；内嵌视频直接在正文中播放 |
| 图像生成失败卡片的“技术详情” | 有可用审核诊断时展开错误代码、审核阶段、类别和请求 ID；没有重新生成按钮 |

执行期间展示过程说明；收到最终回复后，过程说明默认折叠。最终回复下方显示有可靠数据的完成时间和回合用时；过程消息的时间位于其所属图片之后。接收字符数、执行状态、同步状态、代码改动行数和“统计不可用”均为状态展示，不是按钮。

当前网页主时间线没有可点击的工具详情、执行计划或逐文件 Diff 入口。仓库仍保留相关组件，但不能把未接入的组件当作当前页面功能。当前输入区也没有启动实时语音的可见按钮。

### 4.3 历史消息编辑

历史编辑需要会话可交互且未忙碌、没有排队消息、没有正在处理的附件或其他历史编辑。进入后在原用户消息位置出现文本框，底部常规发送区暂时禁用。

| 按钮 | 点击结果 |
| --- | --- |
| 取消 | 放弃本次编辑，恢复原消息显示 |
| 保存并重发 | 从目标消息重新执行；保留原消息附件，同一轮在目标之前的用户消息和附件会一并重发 |
| 确认区的“取消” | 收起删除后续对话确认，回到编辑器，保留已输入修改 |
| 删除后续并重发 | 当存在后续对话时，确认移除目标消息及之后的历史，再发送修改后的内容；更早历史保留 |

历史重发不会撤销已经发生的文件修改、命令执行或外部操作。提交期间按钮禁用；空正文且无原附件时不能提交。

## 5. 输入区、发送与排队

以下描述网页输入区；iOS 使用原生输入框时，应以原生输入栏为准。

### 5.1 输入与附件

| 按钮/操作 | 功能 | 点击后的结果 |
| --- | --- | --- |
| “向 Codex 提问”文本框 | 编辑本次消息；支持多行 | 新版聚焦、换行或带附件时展开输入工具栏 |
| “＋”（添加附件） | 展开附件菜单 | 显示图片、文件、当前位置三个选项 |
| 附件菜单 → 图片 | 选择一张或多张图片 | 打开环境提供的图片选择器；选中后加入待发送缩略图，不立即发送 |
| 附件菜单 → 文件 | 选择一个或多个文件 | 打开文件选择器；选中后加入待发送文件卡片，不立即发送 |
| 附件菜单 → 当前位置 | 请求定位权限并读取位置 | 把坐标、地图链接和精度追加为输入框文字；成功后关闭菜单，仍需手动发送；失败显示错误 |
| 待发送图片缩略图 | 检查图片 | 打开图片预览面板，关闭后回到输入区 |
| 待发送图片/文件的“×” | 移除附件 | 只从当前待发送内容移除，不删除设备原文件 |
| 待发送音频/视频的播放控件 | 本地预览选中文件 | 在当前卡片播放，不提交消息 |
| 输入 `@` | 查找当前项目已安装的 Skill/插件 | 打开候选列表，继续输入可筛选；点击候选会插入提及，随之后的消息调用 |
| 候选列表键盘操作 | 选择提及 | 上下键切换候选，Enter/Tab 选中，Escape 收起；此处 Enter 用于选候选 |
| 最大化/还原输入框 | 仅旧版网页输入区可见 | 扩大编辑区域或恢复原大小，保留内容；新版自动增高，不显示该按钮 |

只读、加载未完成、历史编辑或附件正在处理等状态会禁用相应输入操作。定位中的选项显示“正在定位…”，附件处理时显示“正在处理附件…”。

### 5.2 发送按钮的状态变化

| 当前状态 | 按钮名称/外观 | 点击结果 |
| --- | --- | --- |
| 空闲，有文字或附件 | 发送箭头，名称“发送” | 新对话先创建会话，再发送首条消息；已有会话发送新回合 |
| 空闲，无任何内容 | 发送按钮禁用 | 不提交空消息 |
| 正在执行，输入区没有新内容 | 停止图标，名称“停止” | 请求中断当前回合；不会删除历史，也不等于取消所有排队消息 |
| 正在执行，输入区有新内容 | 发送箭头，名称“排队” | 将文字、附件、提及和当时发送设置提交到网关队列，等待当前回合结束后顺序发送 |
| 正在把队列消息转为引导 | 转圈，名称“正在引导” | 防止重复提交，等待结果 |

只有附件也可以发送或排队。队列得到网关确认后，手机退出、断线或切换会话仍会按顺序发送；提交失败或尚未确认时保留待恢复内容。普通直接发送明确失败时，也可能以失败记录出现在输入区上方，供手动恢复。

如果已有托管队列，即使当前回合暂时空闲、按钮仍显示“发送”，新提交的内容也会继续入队，不会跳过已有待发消息。

### 5.3 输入区上方的排队消息卡片

| 按钮/状态 | 功能与结果 |
| --- | --- |
| 编辑 | 在该队列卡片内展开编辑框，只修改正文/提及，已有附件保留 |
| 编辑框中的“保存” | 保存队列内容，成功后恢复卡片显示；有附件时允许正文为空 |
| 编辑框中的“取消” | 放弃本次编辑，回到原卡片 |
| 取消 | 移除尚未发送的队列记录；正在发送的记录不能取消 |
| 改为引导 | 当前回合仍可接收引导时，将此条排队消息立即用于引导当前执行；输入区上方显示“已发送引导” |
| 重试 | 会话空闲且该记录明确失败时，手动再次提交 |
| 排队中/发送中 | 状态文字；不满足引导或重试条件时按钮禁用 |
| 待确认 | 发送结果不确定，编辑、引导和重试不可用；点击“取消”会先确认，确认后只移除记录，不撤销可能已发送的任务 |

某条发送失败或结果待确认时，该会话后续队列暂停。直接发送失败形成的客户端恢复记录尚未托管到网关，不会自动发送；其“重试”须手动操作。

| 会话 ID 旁的复制图标 | 复制会话 ID |

### 6.3 新版“用量与额度”浮层

再次点击圆环、点击浮层外或按 Escape 可收起。浮层内没有充值、模型切换或重置额度按钮。

## 7. 新对话草稿与草稿箱

| 按钮/入口 | 显示位置与条件 | 点击结果 |
| --- | --- | --- |
| 保存草稿 | 旧版新对话输入区上方；新版新对话右上角“…”菜单 | 将正文、图片、文件、设备、项目和发送配置保存到当前客户端；有附件无文字也能保存，不创建远程会话或上传附件 |
| 草稿箱入口 | 旧版侧栏顶部；新版“Codex → 草稿” | 打开所有设备的本地草稿列表，显示摘要、机器、项目、附件数和保存时间 |
| 点击某条草稿 | 草稿箱中的整条记录 | 关闭草稿箱和侧栏，切到对应设备的新对话页并恢复内容与配置；不会自动发送 |
| 草稿行的“删除” | 每条草稿右侧 | 直接删除该条本地草稿，留在草稿箱 |
| 读取失败时的“重试” | 草稿箱错误提示旁 | 重新读取本地记录 |
| 右上角关闭 | 草稿箱 | 收起面板，不删除草稿 |

恢复后再次保存会更新原草稿。首条消息确认发送成功后删除对应草稿；失败或结果待确认时继续保留。保存期间、附件处理期间、任务忙碌或没有内容时不能保存。

草稿保存在当前浏览器/App 的 IndexedDB，重启仍可恢复，不跨手机同步。目标设备暂停时，恢复草稿会启用它；目标设备已移除时恢复失败，记录仍可查看摘要或删除。普通离开/切换对话不等于点击了“保存草稿”，不能当作已持久保存。

### 8.1 设置入口和层级

旧版“管理设备”将界面模式、传输、通知、字号、设备列表、语言及版本信息放在同一底部面板；添加/编辑设备时显示连接表单。

新版先进入“设置”首页，再通过以下条目进入子页：

| 设置首页条目 | 点击结果 |
| --- | --- |
| 语言 | 进入语言选择子页 |
| 字体大小 | 进入字号子页；仅普通浏览器和 Android 显示 |
| 使用新版界面 | 开关立即保存并切换新旧网页界面 |
| 使用原生界面/使用原生输入框 | 仅支持的 iOS App 显示；先保存切换检查点，下次完整启动时应用；保存失败显示错误并保留原偏好 |

### 8.2 设备列表

每台设备展示名称、地址和连接/暂停/忙碌/待审批状态，一个客户端最多保存 8 台。

| 暂停 | 关闭当前客户端对该设备的启用状态，不关闭远端网关；有未发送队列时先确认丢弃 |
| 启用 | 恢复该设备连接与列表参与 |
| 删除 | 从当前客户端移除设备配置；有任务、待审批或队列时先确认；不会删除远端 Codex 会话 |

### 8.3 设备连接表单与扫码

表单只有“设备名称”和“网关地址”两个主要字段，访问口令放在完整地址的 `?token=...` 中，没有单独的口令输入框。

| 网关地址右侧扫码图标 | 有原生扫码桥时打开系统扫码；否则打开网页扫码面板 |

## 9. 审批、问题与通知跳转

### 9.1 命令、文件和附加权限审批

服务端发来审批时自动弹出面板，展示操作原因、命令、工作目录、网络目标或申请的读写权限。此类面板不能点遮罩收起，没有普通关闭按钮，需要作出决定。

| 按钮 | 结果 |
| --- | --- |
| 允许 | 批准本次请求；附加权限请求按当前回合授予 |
| 本会话允许 | 按请求支持的会话范围授权；附加权限请求使用 session 范围 |
| 拒绝 | 拒绝本次请求；附加权限不授予 |
| 取消本轮 | 返回取消当前回合的决定，仅在请求提供该选项时显示 |
| 允许并记住命令前缀：… | 批准并采用服务端提出的命令前缀规则，仅有对应提议时显示 |
| 允许并记住主机：…/阻止并记住主机：… | 应用服务端提出的网络主机规则，仅有对应提议时显示 |

按钮集合以请求实际提供的决定为准。提交中显示“正在提交，请等待确认…”并禁用重复操作；失败保留面板与错误，成功后移除或展示下一个请求。

### 9.2 “Codex 需要你的回答”表单

面板显示所属会话、问题数量、每个问题及选项说明。所有问题有有效回答后才能提交。

| 按钮/控件 | 结果 |
| --- | --- |
| 选项单选框 | 选择该问题的预设答案 |
| 其他（自行填写） | 请求允许自定义时显示；切换到自由回答输入框，可输入多行；保密问题用密码框 |
| 无选项的问题输入框 | 直接填写自由回答 |
| 稍后回答/右上角收起问题 | 收起表单，在当前连接中保留未提交回答 |
| 页面待回答横幅中的“继续回答” | 重新打开已收起的问题，恢复当前连接中的回答草稿 |
| 提交回答 | 一并提交所有问题；成功关闭，失败保留输入及错误 |

刷新 App 不保存未提交的回答文字；服务端仍待处理的问题会重新同步。另一端已经解决的问题会移除。

### 9.3 其他设备提醒和通知入口

| 入口 | 点击结果 |
| --- | --- |
| “某设备有 N 个待审批”横幅 | 切到那台设备并打开该设备的会话侧栏，不直接替用户批准 |
| 系统/Bark 的会话通知 | 在 App 中定位到通知携带的设备和会话；冷启动时等待初始化和连接后再打开 |

通知方式按设置生效。关注会话可以接收其他端发起任务的完成通知；未关注会话只覆盖手机实际提交的对应指令。结构化模型提问可通知，普通聊天文字中的问句不会触发“需要回答”通知。完成通知要求最终回答及回合成功结束；仅查看会话不等于订阅之后所有任务。

| 入口 | 点击结果 |

## 11. Android 应用更新面板

Android 自动检查发现新版本时打开“发现新版本”，旧版也可从“管理设备 → 检查更新”触发。面板展示新版本、当前版本及跨版本更新说明。

| 按钮/状态 | 结果 |
| --- | --- |
| 稍后/关闭更新 | 暂时收起升级面板，继续使用当前界面 |
| 立即更新 | 下载 APK → 校验安装包 → 打开系统安装器，由用户完成系统安装流程 |
| 重试 | 下载或安装处理失败后再次尝试 |
| 正在下载 N%/正在验证安装包/正在打开系统安装器 | 更新处理中显示进度或阶段，暂时禁用关闭及重复更新 |

iOS 和普通浏览器不使用此应用内升级流程。

## 12. 主要交互链路速查

| 目标 | 操作链路 |
| --- | --- |
| 添加一台电脑 | 旧版管理设备/新版设置 → 设备 → 添加设备 → 输入或扫描地址 → 测试并保存 |
| 发起新任务 | 旧版“聊天”/新版“Ask Codex” → 选机器和项目 → 输入内容或添加附件 → 按需选模型与权限 → 发送 |
| 继续已有任务 | 侧栏点会话 → 输入新内容 → 空闲时发送；执行中先排队，或从队列选择“改为引导” |
| 修改旧指令重跑 | 用户消息编辑 → 修改正文 → 保存并重发 → 如有后续历史，确认删除后续并重发 |
| 暂存新任务 | 新对话编辑内容 → 保存草稿 → 草稿箱选择记录恢复 → 确认后发送 |
| 处理提问 | 自动出现问题表单 → 逐项回答 → 提交；或稍后回答 → 点击“继续回答”恢复 |
| 查看产出 | 对话中的文件名/图片 → 对应预览 → 查看或下载 → 关闭回对话；内嵌视频直接播放 |
| 切换网页版本 | 旧版管理设备 → 开启“使用新版界面”；新版“Codex → 设置” → 关闭同一开关 |
