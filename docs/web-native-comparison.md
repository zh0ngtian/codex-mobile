# iOS 原生与网页界面对比

## 切换入口

打开会话边栏 → 管理设备 → 界面体验，选择「原生界面」或「网页界面」，然后关闭面板。iOS 默认原生；选择仅保存在当前客户端，重启后沿用。Android 和普通浏览器使用优化后的网页界面。

两个模式共享设备连接、历史、当前会话和未发送草稿。切换不会重新建立 App 或会话；从网页切回原生会重新投影当前数据。原生「完整内容」仍是单个会话的临时网页查看入口，界面体验切换会重置该临时状态。

## 建议比较顺序

1. 打开同一会话，阅读短用户消息、长回复、代码和宽表格。
2. 输入一段草稿，不发送；比较输入区域、键盘打开与收起、长草稿展开。
3. 打开边栏，比较搜索、无结果清除、设备与项目选择、列表滚动、会话管理。
4. 在设备管理切换界面；确认同一段草稿仍在。可分别开启系统深色和大字号再比较。

## 同一视觉基准

两者沿用黑白灰、内容优先的规范：默认正文17pt/px、手机阅读左右20、输入左右12、触控至少44、控件间距8、正文最大720、边栏最大420。网页版使用语义颜色，iOS 注入系统正文缩放并叠加客户端字号；宽表格仅自身横向滚动。

| 比较点 | 原生界面 | 网页界面 |
| --- | --- | --- |
| 列表与输入 | UIKit 控件、原生键盘布局 | React/CSS、WKWebView 输入 |
| 会话菜单 | 系统原生菜单 | 公共 ActionSheet，支持键盘和焦点恢复 |
| 正文 | 原生 Markdown 分块排版 | 网页 Markdown 排版 |
| 数据和草稿 | 同一业务层持有 | 同一业务层持有 |

本轮验证用于功能和可读性比较，未做两种方案的性能基准测量；模拟器验证不代表真机覆盖升级与数据保留已验证。
