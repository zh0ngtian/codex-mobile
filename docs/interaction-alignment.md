### 4.1 发送按钮与输入框

| 状态 | 显示与点击行为 |
| --- | --- |
| 空闲，无文字也无附件 | 发送禁用 |
| 空闲，有文字或附件 | 显示发送箭头；新对话先创建会话再发送 |
| 执行中，无新内容 | 显示停止，只中断当前 turn，不取消整个队列 |
| 执行中，有新内容 | 显示排队箭头，提交文字、附件、提及和当时配置 |
| 正在把队列内容转为引导 | 显示等待状态，防止重复提交 |
| 已有托管队列 | 后续提交继续入队，不越过已有待发消息 |

- 发送按钮采用 regular 尺寸的原生圆形按钮，避免 large 控件在输入栏中过大；发送、停止、排队和引导中的状态逻辑保持一致。
- 输入框随手动换行或自动折行自然增高，达到最大高度后内部滚动，删除文字后缩回；不提供最大化图标。
- 键盘展开、交互式收起和关闭时，输入区同步跟随，不残留悬空空白；切换会话不能把旧输入、焦点或选择状态带到新会话。
- 用户消息长按可以复制完整原文；历史编辑仍在原消息位置进行。应用不提供自己的听写麦克风或实时语音入口，系统键盘由 iOS 管理。

### 4.2 侧栏视觉、标记、顺序与搜索

- 侧栏保留屏幕宽度 **4/5**。在页面普通内容区向右滑呼出、向左滑收起，位移随手指更新，松手按进度/速度完成或回位；主界面整块（含系统导航栏和输入区）向右移动，露出后方侧栏，并以大圆角和柔和阴影分层，取代旧灰色遮罩和竖边线。露出的主界面区域可点击收起。纵向阅读、编辑输入、已有文字选择及内容区横向滚动不触发抽屉（左缘仍可呼出）；设置、预览、审批和历史编辑等呈现期间不抢手势。
- 按参考图直接显示关注会话，再按业务顺序显示项目，不显示“关注”“项目”分组标题或关注折叠按钮，也不恢复“最近”分组。无项目且未关注的会话仍可通过搜索找到，不删除数据。
- 项目、会话、分组标题、设备范围与辅助文字使用系统默认正文大小和字重，跟随系统 Dynamic Type 与“粗体文本”设置；不恢复原型的 18/15/14.5/12.5/11.5pt 字号矩阵。
- 会话行上下内边距各 6pt、最小高度 44pt，列表项间距 0；分组标题上/下留白 10/2pt。文字变大或折行时不能截断必要操作。
- 会话名单行并在过长时尾部省略；未读点与运行转圈紧跟名称，共用名称后方的状态位置，不靠列表最右侧；运行转圈额外增加2pt左间距，项目汇总同样处理；运行、待处理和连接异常状态优先，空闲未读才显示圆点；名称左侧不再留出未读点位置。去掉可见的“运行中”“未读”“已就绪”，但保留未读数据、圆点、连接异常和待审批等有意义状态。
- 折叠项目的未读点与运行转圈同样紧跟项目名，共用名称后方的状态位置；运行优先，待处理计数保留。关注会话不重复出现在原项目，不计入项目内汇总。
- 原生层严格使用业务投影顺序，包括目录顺序与业务已有的时间排序规则；搜索分组按首次出现顺序去重。不得按字典键或字母重新排序，也不恢复已回退的项目拖动排序方案。
- 项目展开和收起使用约0.25秒高度过渡，内容稳定挂载并裁剪；展开时先拉开空间，再以约0.18秒渐显会话，异步加载导致的内容高度变化也沿用过渡；收起时立即隐藏会话文字，避免退出文字与上移项目标题重叠；侧栏松手后使用0.5秒弹簧响应完成打开或关闭，跟手拖动不变，遵循系统“减弱动态效果”。当前会话不使用选中背景高亮。
- 项目名与图标均可展开或收起；不显示项目前的展开箭头或项目右侧编辑/新建图标。折叠时隐藏“加载更多”，展开后才显示灰色分页入口。

- 验收要点：搜索与省略号圆形外观及尺寸一致，仍可展开/清空并聚焦；Chat 图文对比清晰、尺寸与留白接近参考且仍进入新对话；搜索、省略号与 Chat 高度一致，菜单完整保留设备、草稿、刷新和设置。

- 底部 Chat、搜索与省略号以透明 overlay 直接悬浮于侧栏之上，不再占据单独页脚或铺设整行容器背景；仅按钮自身有玻璃表面，列表末尾保留避让空间。关注会话的文字左端与文件夹图标的画布左端对齐，未读点紧跟标题，不靠列表最右侧。

### 4.3 用量与额度

所有原生页面（包括新对话和参考界面）统一使用 SF `circle`；点击对话顶部的新建按钮左侧圆圈，打开“用量与额度”卡片；图标不再自绘或显示上下文进度弧，全部用量与额度入口均固定使用黑色图标，不添加独立白色圆底或高亮底色，与相邻按钮共用系统背景，不随强调色或数据缺失改变。数据值仍由弹层展示。页头采用系统导航栏，使用原生标题/副标题；右上三个按钮在同一 ToolbarItem 内紧凑排列，间距0、各44pt触区，抽屉、用量、新建和更多图标统一16pt字号及画布。左侧抽屉与右侧按钮垂直居中对齐，表面同高。抽屉入口使用 SF `line.3.horizontal`，顶部 SF Symbols 使用 regular 字重，副标题仅显示项目名与设备名，不显示完整路径。

| 项目 | 现行口径与状态 |
| --- | --- |
| 上下文余量 | `1 − 最近一次请求 Token ÷ 上下文窗口大小`，不使用累计 Token 代替最近请求 |
| 额度剩余 | 当前账户 7 天额度剩余百分比；已取代“周期剩余”名称 |
| 刷新时间 | 替换原“时间剩余／剩余时间”。读取账户 7 天窗口真实 `resetsAt` 并显示倒计时，例如 `4d15h (66%)`；剩余小时向下取整，百分比为真实剩余秒数 ÷ 604800 × 100 四舍五入为整数，卡片打开时每分钟更新；过期显示 `0d0h (0%)` |
| 输入 Token | 当前会话累计输入量；缓存比例有效时示例 `100K (缓存命中 80%)`，缺少有效缓存数据时只显示 Token 数，不显示括号或缓存占位文字 |
| 输出 Token | 当前会话累计输出量，例如 `28.5K` |

- Token 使用十进制 K/M（K = 1,000、M = 1,000,000），最多一位小数，去掉 `.0`，避免边界显示成 `1000K`。
- 缓存比例为累计缓存输入量除以累计输入量，最多一位小数；有效的 `0%` 需要显示。缺失、非有限数、负数、输入为零或缓存量大于输入量时不展示缓存括号。
- 百分比只在有可靠数据时显示整数百分比；缺少上下文、额度或累计 Token 时显示“暂无数据”，不虚构 0% 或 100%。刷新时间按设备隔离，新对话尚未创建会话时也读取账户窗口；缺失或无效时显示“暂无数据”，不用当前时间或窗口长度推算，也不拿 5 小时窗口替代 7 天窗口。
- 账户额度与会话 Token 分开统计；真实事件或已持久化的只读数据是来源，不为展示用量额外 resume 历史会话。
- 数据变化时实时更新；切换会话、设备或隐藏工作区时收起。点击外部、再次点击圆圈或按 Escape 可关闭。
- 历史说明：刷新时间更名前，“时间剩余”曾表示账户 5 小时额度剩余百分比，不是距重置时刻的比例。这是旧口径，不能直接当作新“刷新时间”的定义。

### 4.4 模型、思考强度、速度与权限

- 输入区依次提供附件、权限、Fast 闪电、模型名、独立思考强度及发送入口；加号、权限盾牌与Fast闪电使用系统subheadline，比原body基准小2pt，横向40pt、纵向44pt，继续跟随系统字号与粗体设置。闪电、模型名和思考强度在权限按钮右侧靠左排列；模型与闪电间距为8pt，模型和强度之间同样为8pt，不显示上下箭头。
- 点击模型名打开仅含模型的原生菜单；模型右侧显示当前思考强度，点击该独立按钮选择当前模型真实档位。两个菜单均为普通菜单按钮，不显示选择勾，外部单击关闭；覆盖此前把强度放入模型菜单的入口，不恢复旧模型页、卡片或滑杆。
- 权限入口单击直接弹出系统Menu，不再打开权限sheet；保留各模式名称、说明和图标，原生action在显示前准备完整标题与subtitle；仅权限菜单本次打开关闭分阶段文字动画，使主文字和灰色说明同步出现，不改变全局动态效果设置。菜单不显示选择勾，点击外部关闭。选项及顺序来自当前业务权限目录，命令保留真实value并携带打开时的会话context；连续选择保留最后意图，旧会话、只读、侧栏打开、历史编辑或业务pending时不可执行。空目录时入口禁用，当前权限仍由图标和辅助功能value表达。
- 模型名和闪电使用中性主文字色（浅色为黑色，深色自适应），均不使用灰色或强调色。闪电在模型名左侧独立点击切换普通/Fast，不打开菜单；普通为 SF `bolt`，Fast 为 `bolt.fill`。仅当前模型支持时可用，切换模型等待权威能力快照时不能显示/提交旧模型的强度或速度。
- 模型、强度与权限菜单各自由自身选项、当前值、上下文、语言及可编辑状态驱动；消息、用量和命令回执快照不重建已打开的菜单，滚到底部不回跳。
- 每个模型单独读取业务能力目录，不硬编码 Sol/Luna 档位或借用其他模型的档位；没有有效强度或模型快照未回填时强度入口不可用，不显示旧模型档位或填造数值。模型切换后由真实业务按新模型归一化，菜单命令携带打开时的会话上下文，旧会话菜单不能影响新会话。
- 连续点击 Fast 或连续选择模型/强度，即使快照尚未回填，也必须提交最后一次选择，不能因为旧快照与目标值相同而丢弃后续意图。菜单和闪电均沿用真实业务命令、只读限制及配置作用域。
- 新对话的模型、强度、速度按设备记忆；已有会话更新线程配置，权限用于后续提交；队列冻结入队时的配置。协议未返回冻结配置时明确表示未返回，不套用当前值。

- 开启系统 Show Borders 时，输入区发送/停止/排队按钮使用清晰的 34pt 圆形填充，不叠加系统玻璃按钮的额外黑色轮廓；只调整该按钮的外观，不关闭系统设置，其他控件继续遵循 Show Borders。未开启时沿用原生玻璃按钮；禁用状态、图标、业务命令和触感规则保持。
- 发送/停止按钮按 2026-10-18 两张输入框裁图向内定位：保留 34pt 视觉直径，右侧留白 12pt；收起框高 58pt、垂直居中，上下各约 12pt；展开后的按钮底部留白约 13pt。左侧图标与现有模型/强度入口保持原位置和业务行为。
- 有效发送与停止操作使用系统默认 impact 触感，不自定义强度；禁用按钮和仅选择提及不触发提交触感。模拟器验证接入及业务状态切换，实际振感由真机与系统设置决定。

### 4.5 字体、强调色与菜单

- iOS 没有已保存的界面/颜色偏好时，默认原生界面和黑色强调色；保留已有明确选择，网页界面开关继续通过原检查点保存与下次完整启动生效。强调色突出按钮明确设置对比前景；绿色、橙色、青色、青柠和黄色采用黑色图文，其他彩色主题采用白色图文，黑色主题采用反向明暗文字。

- 界面和用户气泡采用系统正文样式；导航标题/副标题、表单分组及注释使用原生系统层级。回答正文按 2026-10-18 参考截图校准：17pt 系统基准经 UIFontMetrics 正文曲线缩放并取整，当前模拟器 XS 设置为 15pt，气泡仍为系统正文 14pt；继续跟随 Dynamic Type 与“粗体文本”。Markdown 标题使用回答正文大小和显式加粗，普通文字与 Markdown strong 保持不同字重；不能把系统粗体环境直接转换为所有文本的 strong。代码保持对应正文大小的系统等宽字体。
- 会话重命名使用系统弹窗，保存、取消及正文使用中性色，不继承应用强调色。context menu、会话操作菜单及其他弹出菜单的普通文字和图标使用中性色；危险操作保留系统危险操作颜色。
- 设置、设备管理中的导航、按钮、开关和选中状态使用中性色；强调色选择器的色样显示其真实颜色，以加宽画布留白增加圆点与文字的间距。
- 输入区及待添加列表中的图片缩略图在明确尺寸内缩放裁剪，竖图不越过容器。
- 图片预览工具栏左侧为下载，右侧为关闭；其他文件格式保留原工具栏位置。缩放、导出和取消预览行为不变。
- 图片在消息中直接展示，不再于下方显示名称和展开符号；点击图片仍打开原预览，名称保留在辅助功能标签与预览标题。文件卡片、占位图标、预览工具栏、源码定位等使用中性色，不继承强调色；图片本身保留原始颜色。
- 粉色主题的用户消息气泡按参考图使用浅粉底 `#FFEFF4` 和深粉文字 `#CC0078`；深色与其他强调色继续使用相应主题。字重跟随系统，不因参考截图强制加粗。用户消息完整显示，不再提供“展开更多／收起”按钮。
- 首次启动、连接、导航、项目分页、历史消息及“正在执行”前的加载图标使用中性色。运行转圈标记与提交按钮的业务状态分别处理，不将加载状态当作成功。

### 4.6 对话内容、commentary 与滚动

- 移除用户消息末尾多余空白行造成的展示空行；复制、编辑与发送使用原文，不修改消息内容。
- 完成过程按参考代码放入最终回复的 `message.commentary`，运行过程使用 `conversation.liveCommentary` 与原有 `CommentaryHistoryView`，适配时保留真实消息顺序和归属。
- 执行过程只展示 commentary；工具调用、推理与执行计划不在消息区显示，底层快照、命令身份、审批及实际媒体产出保留。完成后 commentary 默认折叠，入口改为“用时xxx”；缺少可靠计时数据时按用户确认显示“执行过程”，保留点击展开。展开后展示真实正文、所属媒体和分钟粒度时间，reasoning 与工具调用继续隐藏。
- 运行中的 commentary 仅展示一次统一灰色时间；呈现时过滤旧投影中消息ID加`:timestamp`标识的结构时间块，保留正文中作者写入的日期和底层原始块。
- 每条 commentary 后使用灰色分隔线，包含运行中尾段、独立条目和折叠历史展开后的最后一条。媒体跟随对应条目展开或收起，不能重复显示，也不能为无数据条目附加空复制行。
- 移除 final answer 下方的复制按钮；末尾仅保留可用的完成时间，耗时移到回答前的过程入口；没有 commentary 但有可靠用时时只显示用时文字。代码块复制和正文选择不因此取消。回复正文使用系统选择手柄选择任意片段，相邻正文、标题、引用与列表可跨段连续选择；代码与表格内容在各自区域内可选择。
- 链接下方使用点状虚线；普通正文不额外加下划线，代码示例路径不自动变成文件按钮。原生正文直接绘制独立圆点，避免系统点线退化为短横线。
- 回复尾部和 commentary 时间同样使用 `M月d日 HH:mm`，保留各自已有位置；刷新时间使用第 4.3 节的七天窗口倒计时。
- 任务用时按真实总毫秒拆分，省略为 0 的小时和分钟，秒保留；数字与中文单位不留空格，过程入口显示“用时”前缀，例如 `用时15秒`、`用时1小时3秒`、`用时2分钟0秒`。分钟和秒按 60 进位，不将其他业务状态解析成耗时。
- 不显示代码增删行数统计或独立“文件变更”按钮；这不表示删除远端文件、历史或工具执行记录。
- 移除“加载历史消息／加载更早消息”按钮。第一次用户划到顶部及同一手势继续下拉均不加载；松手后下一次独立下拉才加载，每个手势最多请求一次。
- 初始布局、惯性和程序滚动不能直接触发历史加载；加载中和无更多历史时不重复请求，失败可再次下拉重试。
- 会话已加载的消息使用完整布局，避免长系统文本视图与惰性高度估算在滚动后留下空白；历史数据仍按需分页读取，不预先拉取全量历史。正文首次布局即提供解析后的 Markdown，使用有界缓存复用，流式内容变化重新解析；不再先用零高度正文跳转、异步解析后回填。会话详情尚未返回且无正文时显示中性加载提示。
- 手动回到底部以约1.2秒起止平缓的动画通过列表末尾 ID 锚点定位（减弱动态效果时直接定位），动画中用户拖动可取消，不按尚在变化的内容高度直接长距跳转；持续输出时动画transaction的完成回调可能早于实际滚动，不能在该回调中执行无动画补跳；以真实几何到达底部且滚动停止后交接自动跟随，期间保持手动回底请求，避免新消息抢占动画。确认落到底部后恢复附件高度回填跟随，用户开始滚动即取消跟随。自动跟随由用户滚动意图决定，不拿新增内容后的几何 atBottom 反推；用户开始拖动即停止，主动回到底部或手动到达底部后恢复。容器尚未挂载时保留未完成锚点请求并在入窗后执行。所有自动定位及高度回填也统一请求末尾 ID，UIKit 只观察内容高度变化，不再按估算高度设置偏移，避免与惰性布局互相干扰。历史前插继续使用稳定消息 ID 锚点；旧消息插入保持阅读位置；回合合并导致呈现 ID 改变、图片回填或同一会话重新打开，都不能造成跳到底部、定位丢失或永久加载锁。
- 非最底部时在输入框上方居中显示中性圆形下箭头，点击滚动到最新消息，回到底部后隐藏；短会话全部可见时不显示。程序跳转不能被当作下拉历史手势。
- 用户消息气泡取消折叠阈值与折叠状态，长消息完整显示并通过页面滚动阅读；保留单击时间、自由选择、复制和原位编辑。
- 历史编辑原位出现时自动聚焦、弹出键盘并将编辑位置移入可视区；保存重发按钮使用中性高对比文字和背景，后续消息删除确认不变。
- 用户消息默认不显示发送时间；单击气泡后在右下角外侧显示，再次单击隐藏。显示格式为 `M月d日 HH:mm`（例如 `10月17日 10:43`），优先使用消息时间，其次使用所属回合开始时间；缺失或无效时不显示，不能用现在的时间补造历史记录。

- Markdown表格按用户参考采用白底、浅灰细横线、无竖线与外框的样式；表头保留strong语义，正文使用系统subheadline（比body基准小2pt），继续跟随系统字号与粗体设置。列宽按内容自然宽度计算并将单列限制在260pt以内；长内容恢复自动换行，不截断内容，超宽整表仍可横向滚动，保留文字选择、链接、图片及HTML作用域。
- 队列消息的“取消、编辑、改为引导”按此顺序同排显示，各自的可用条件保持；失败重试仍独立，取消待确认消息的风险确认保留。
- 原生归档确认将现有带key的业务confirmation panel呈现为系统小alert，不再展示整页sheet；确认与取消沿原命令结算，关闭弹窗不会重复取消或复用旧确认身份。

### 4.7 系统控件与材料

- 已确认参考 DailyMusuem：使用系统 NavigationStack、导航栏副标题、ToolbarItemGroup、Form/Section、Picker/Toggle/LabeledContent 和步进 Slider。保留 4/5 侧栏、消息区与真实业务绑定，页头排布交由系统。
- 对话和新对话页不再将自绘页头塞入顶部 safeAreaInset；侧栏打开时隐藏主导航栏，关闭后恢复。设置/设备/语言/传输/通知使用系统导航和表单/列表，保留原保存及失败语义。
- 悬浮输入使用 iOS26 原生 Liquid Glass API，模型与强度使用系统菜单；发送、回到底部、新对话目标等使用系统按钮样式，多个玻璃表面使用 GlassEffectContainer。去掉控制区域手工描边和阴影，不把所有内容卡片都改成玻璃。
- 编辑器通过标准 safeAreaInset 保持输入焦点与键盘跟随；当前 iOS26.5 的 safeAreaBar 承载编辑器时出现焦点不同步，已通过回归定位并使用系统 inset 修复。最新材料和导航控件继续生效。
- 最低 iOS18 支持保留，系统支持新材料时采用对应 API；较早系统使用标准系统控件。DailyMusuem 本身不做修改。

### 4.8 ProMotion

- 应用构建启用 `CADisableMinimumFrameDurationOnPhone`，全局窗口在前台通过被动 `UIUpdateLink` 表达最高 120 Hz 偏好；低刷新率设备按其屏幕上限处理。
- 不安装常驻逐帧回调，不强制静止页面持续绘制，进入后台停用。实际刷新率仍由 iOS 根据交互、设备、电量及温度动态调度；构建开关和界面回归不代表已测得真机固定 120 帧。

## 5. 功能流程约定

以下流程由原型清单导入并按真实业务边界修订；列入约定不代表本次已对每一条重新验证。

### 5.1 设备连接与管理

- 无设备引导、首次添加连接表单、设备列表、编辑、拖动排序和添加均不设置设备数量上限；移除八台提示、禁用及配置恢复截断，仍校验重复地址/设备身份和真实网关访问。
- 设备行不提供操作菜单、暂停/启用、上下移动或行内删除；进入排序后隐藏右箭头并禁止进入编辑，退出后恢复。
- 编辑已有设备的页面底部提供删除，添加时不显示；删除前明确确认，保存或测试中不可删除。删除本机配置后处理相关本地任务与待处理请求，但保留已保存草稿。
- 展示真实连接、失败、忙碌和待审批状态。名称与完整网关地址是主要字段，地址可包含访问口令，不另设重复口令栏。
- 扫码或从相册识别后填入地址，仍需点击“测试并保存”；测试中防重复，成功返回列表，失败保留输入和错误。

### 5.2 草稿箱

- 新对话菜单保存草稿，Codex 菜单进入草稿箱；列表包含摘要、设备、项目、附件数、保存时间、恢复、删除和读取失败重试。
- 恢复正文、完整附件、设备、项目和发送配置，不自动发送；再次保存更新同一草稿。
- 首条消息确认成功后清除对应草稿，失败或结果待确认时保留；普通离开或切换对话不等于明确保存。
- 草稿在当前客户端重启后可恢复，不跨设备自动同步。移除目标设备不等于删除草稿。

### 5.3 排队与失败恢复

- 输入区上方显示排队、发送、失败和待确认；支持编辑、保存、取消编辑、取消排队、重试及改为引导。
- 编辑只改正文与提及，保留附件；入队冻结正文、附件、提及和配置。
- 待确认时限制编辑、引导和重试，取消前确认；移除队列记录不表示撤销可能已发送的任务。
- 失败或结果待确认时暂停后续队列；直接发送失败的恢复记录由用户手动重试。退出后的发送与托管行为沿用真实网关契约，不以原型模拟承诺替代。

### 5.4 执行中的审批

- 与权限模式选择分开，按实际请求显示命令、文件和附加权限审批，包含原因、命令、工作目录、网络目标及读写范围。
- 允许、本会话允许、拒绝、取消本轮、记住命令前缀或主机规则等决定按请求提供，不固定拼出全部按钮。
- 有多个主机或同类决定时保留独立选择与目标，不能静默只提交其中一个。
- 不通过遮罩或普通关闭按钮收起，必须作出决定；提交中防重复，失败保留面板和错误，权威结果确认后继续下一个请求。

### 5.5 “Codex 需要你的回答”

- 支持单选、自由回答、多行、保密输入及所有问题的有效性校验。
- 支持稍后回答、收起、待回答横幅和继续回答，与审批的强制决策规则分开。
- 当前连接中收起再打开保留未提交答案，失败保留输入；刷新后重新同步待处理问题，不承诺持久化未提交文字。
- 只有权威请求消失或确认解决后才移除，不因本地成功提示屏蔽仍待处理的请求。

### 5.6 历史编辑与只读

- 每次向前读取五个旧回合，使用第 4.6 节的二次下拉门控和阅读位置保持规则。
- 历史加载与详情加载失败可以重试；只读历史仍可阅读，发送与修改禁用，必要时提供重新连接入口。
- 用户消息在原消息位置编辑，支持取消、保存并重发；存在后续历史时确认“删除后续并重发”，保留更早历史与原附件。
- 明确重发不会撤销已经发生的文件、命令或外部操作。

### 5.7 提及与产出预览

- 输入 `@` 显示当前项目 Skill/插件候选，支持筛选、选择和键盘操作。
- 图片支持缩放、还原、平移、下载及适用的重试；远程文件支持预览/源码、行号定位、下载、二进制提示和读取错误。
- 支持内嵌视频及视频文件预览；Mermaid 支持预览/源码，复制始终复制源码，渲染失败显示源码。
- 文件引用走对应设备的既有文件读取或下载，普通网页链接走普通浏览器行为。保留中文、空格和括号等文件名，显示净化不能改变复制与编辑的原文。
- 不把纯代码示例中的路径变成文件按钮；预览控件配色遵循第 4.5 节。

### 5.8 通知与跨设备跳转

- 通知设置使用中性色；Bark 输入栏以灰色占位提示 `https://api.day.app/BARK_DEVICE_KEY`，不视为已填入的地址。
- 不显示“通知范围”和“模拟通知”区块，保留任务通知开关、通知方式、必要地址及保存。修改先成为候选配置，保存才生效，返回或关闭丢弃未保存修改。
- 其他设备待审批横幅切到对应设备与会话列表，不直接批准；系统/Bark 通知定位对应设备和会话，冷启动等待初始化与连接后再跳转。
- 完成通知仍沿用关注会话或手机提交任务等业务筛选；只对结构化模型问题触发待回答通知，不将普通聊天问句当作请求。
- 保持现有防重复、初始同步与断线追赶的通知规则，不因为隐藏范围设置而取消业务筛选。
